# Jobs

One folder per tailored job, named `YYYY-MM-company-role` (e.g. `2026-10-examplecorp-head-of-operations`).

Each folder holds:
- `resume.md`, tailored from the current master
- `cover-letter.md`
- `notes.md`: job description summary, link, change log, gaps, release-check summary, date applied, outcome
- `exports/`: the PDFs you actually uploaded

The folder name is the version. Commit messages say what changed and why, e.g. `examplecorp: lead with vendor management; condense 2012 role (JD emphasis)`.
